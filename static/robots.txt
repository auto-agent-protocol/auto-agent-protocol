# Content Signals (contentsignals.org) — AAP is an open standard and WANTS to be
# used by AI: allow model training, search indexing, and AI input/grounding.
# The Content-Signal line is repeated in EVERY group deliberately. Per RFC 9309
# section 2.2.1 a crawler obeys the group matching its own product token and
# falls back to the "*" group only "if no matching group exists", so a signal
# declared once under "*" is never read by any crawler named below — i.e. by
# none of the AI crawlers it is written for. Do not deduplicate these lines.
#
# Nothing here is Disallow-ed on purpose: superseded doc versions are kept out
# of search with a per-page noindex tag (see docusaurus.config.ts), and a page
# blocked in robots.txt can never be crawled to discover that tag.
